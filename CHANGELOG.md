# Changelog

Версії за [SemVer](https://semver.org/lang/uk/).

## [0.1.0] - 2026-11-12

Перший реліз.

### Додано
- FORM-01: зведення КВ-граматики (непродуктивні й недосяжні нетермінали), видалення ε-правил і ланцюгових правил, нормальна форма Хомського з поясненням кожного кроку (`sipl-formal cnf`).
- FORM-02: система рівнянь над мовами за граматикою, послідовні наближення від ∅ і порівняння з мовою граматики на словах обмеженої довжини (`sipl-formal equations`).
- FORM-03: Pumping Lemma Explorer для мов-шаблонів з одним параметром n (`sipl-formal pump`).
- FORM-04: лівосторонні й правосторонні виводи, дерева виводу, пошук кількох дерев для слова, експорт у текст, JSON і DOT (`sipl-formal derive`).
- CORE-01: граматика SIPL у Lark, 12 правильних і 12 неправильних прикладів (`sipl-formal sipl-check`).
- VIS-01: дерево синтаксичного виводу SIPL-програми з позиціями у тексті, експорт у текст, JSON і DOT (`sipl-formal sipl-tree`).
- `demo.ipynb`: демонстрація всіх модулів із клітинками для нових прикладів.
- REL-01: GitHub Actions: ruff, mypy, pytest і збірка пакета на Python 3.10, 3.12, 3.13.
